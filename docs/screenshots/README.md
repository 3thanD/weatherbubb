# Screenshots

Drop PNGs here using the filenames referenced by the project README:

| Filename | What it should show |
|---|---|
| `dashboard-space.png` | A full dashboard — clock, jokes, on-this-day, sports, an image bubble |
| `dashboard-forest.png` | Merged stock bubble, to-do list, quick links, timer, quote |
| `sidebar.png` | The menu open, showing settings, themes and layout controls |

Keep them under ~500 KB each so the README stays quick to load. PNG for UI,
since screenshots of text compress badly as JPEG.
